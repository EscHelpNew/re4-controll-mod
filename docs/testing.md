# Проверки RE4 Controls

Общий запуск на Windows из корня репозитория:

```powershell
.venv\Scripts\python.exe build.py --test
.venv\Scripts\python.exe build.py --module --overlay --nro
```

Первая команда запускает Python unittest и тридцать собственных C++ программ
проверки. Для native-проверок действует тайм-аут20секунд: окно аварийного
assert в Windows не оставляет автоматический запуск зависшим.

В host-проверках заменяются внешние API Switch/Tesla и вызовы самого движка.
Это проверяет собственные обработчики и протоколы, но не воспроизводит
рендеринг, прошивку или весь код игры. Сборка ARM64 отдельно проверяет реальную
линковку с SDK и формат контекста перехватов.

Обработчики игрового модуля и движения в CI компилируются с C++20, как настоящий
модуль, с `-Wall -Wextra -Werror`. Качество нового вида от первого лица, движения
ног и столкновений0.7 на консоли пока не подтверждено; хост-тесты не заменяют
эту проверку. Версия совместной структуры —13, размер400байт.

На консоли подтверждены пользователем: повороты, ходьба, камера, прицел,
совместный гироскоп только при наведении из оружия, полный вертикальный
диапазон после исправления, подсказки и предел1.00 (0.2.2).
Замена NRO с новым PID/SHA и запуск после перезагрузки также проверены.
Для особого оружия, всех кат-сцен/QTE и всех вариантов смены контроллера
полная аппаратная приёмка пока не выполнена. Стопроцентное покрытие строк кода
и внешних библиотек не заявляется.
В0.3.0 пользователь подтвердил запуск графического установщика и установку мода.
Пользователь также подтвердил EN/RU, четыре кривые внутри игры и удаление
пункта скорости ходьбы. Обновлённый NSP установлен через DBI (FTP226 и
подтверждение пользователя). Извлечённая из его Control NCA иконка проверена:
это предоставленная красная «4» в прицеле; NACP содержит версию0.3.0.
В0.3.1 пользователь подтвердил восстановленный гироскоп, новый фильтр/настройки
и правильный значок после автоматического обновления HOME.
В0.4.0 подтверждён правый стик: X/Y0.00 останавливает прицел, при0.30 скорость
меняется от отклонения. Гироскоп, обычная камера и левый стик регулируются отдельно.
Автоматически проверяются собственные NCA/метаданные, обновление и откат HOME,
манифест OTA, TLS-параметры, отмена, SHA/NRO/NACP/версия, оба файла приложения,
восстановление после неудачной замены и защита от понижения версии.
Проверка анонимной загрузки OTA на консоли отложена до открытия репозитория;
сейчас пользователь попросил оставить релиз приватным.
