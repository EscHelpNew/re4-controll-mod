# Проверки RE4 Controls

Общий запуск на Windows из корня репозитория:

```powershell
.venv\Scripts\python.exe build.py --test
.venv\Scripts\python.exe build.py --module --overlay --nro
```

Первая команда запускает Python unittest и восемь собственных C++ программ
проверки. Для native-проверок действует тайм-аут20секунд: окно аварийного
assert в Windows не оставляет автоматический запуск зависшим.

| Код | Автоматическая проверка |
|---|---|
| Ввод, повороты, гироскоп | Мёртвые зоны, монотонность, насыщение, углы ±pi, свежесть показаний, 30/60FPS, высокие чувствительности, одновременный ввод |
| Формат настроек | Контрольная сумма, NaN, диапазоны, предел1.00, миграция v1/v2→v3, сохранение пользовательских настроек |
| Файлы настроек | Замена, восстановление из предыдущего файла, сохранение после повреждения первичного |
| Установщик | Отсутствующий payload, чужие файлы, идемпотентность, собственное обновление, отключение и предыдущие копии |
| SD оверлея | Ошибки открытия/монтирования, владение устройством, повторный mount/close |
| Датчики | Выбор контроллера, отказ службы, отсутствие повторных start, границы массива, отключение |
| Игровой адаптер | Выполняется настоящий module.cpp: проверки профиля, временные кнопки и темп анимации, D-pad, quick-turn, оба формата камеры, гироскоп+стик, пауза, выключение прицела и отключение контроллера |
| Вертикальный гироскоп | Повторное движение выходит за узкое окно покачивания; настоящий callback помечает гироскоп ручным вводом для обновления штатной опорной позиции |
| Меню | Выполняется настоящий main.cpp: описание каждого выделенного пункта, отсутствие записи при наведении, пределы скорости, сброс значений и переключателей |
| Обмен с игрой | Выполняется настоящий game_link.cpp: идентификация, границы карты памяти, порядок odd/payload/even, обрыв каждого этапа записи, отказ после перезапуска игры и при старом ABI |
| NSO-инспектор | Хеши, LZ4, архитектура, пересечения и повреждённые сегменты |
| Упаковка | Все хеши manifest, отсутствие ключа/игровых файлов, очистка устаревшего загрузчика, отказ при неоднозначном NSP и постороннем пути |
| Передача/ярлык | Корень конфигурации и явный ключ, FTP rollback и запрет NRO через FTP, сохранение прежнего ярлыка при ошибке сборки |
| Иконка | Сохранность оригинала, JPEG RGB256×256, допустимый размер |

В host-проверках заменяются внешние API Switch/Tesla и вызовы самого движка.
Это проверяет собственные обработчики и протоколы, но не воспроизводит
рендеринг, прошивку или весь код игры. Сборка ARM64 отдельно проверяет реальную
линковку с SDK и формат контекста перехватов.

На консоли подтверждены пользователем: повороты, ходьба, камера, прицел,
совместный гироскоп только при наведении из оружия, полный вертикальный
диапазон после исправления, подсказки и предел1.00 (0.2.2).
Замена NRO с новым PID/SHA и запуск после перезагрузки также проверены.
Для особого оружия, всех кат-сцен/QTE и всех вариантов смены контроллера
полная аппаратная приёмка пока не выполнена. Стопроцентное покрытие строк кода
и внешних библиотек не заявляется.
