# Weapon UI implementation plan

1. Trace native HUD/text/name and attache firepower APIs; authenticate instruction
   sites and document ABIs. Trace pickup fade and sound before changing callbacks.
2. Add and test a latest-only popup timeline, committed-equip notification and
   D-pad-setting/HUD visibility gates. Render matching text with shared mist fade.
3. Add actual callback fixtures for selected firearm power and native pickup
   effects, including failed/full inventory paths and duplicate sound prevention.
4. Integrate guarded native sites and helpers, retaining the existing hook budget.
5. Run the required host suite, ARM module/overlay/NRO builds and public/history
   audit; review changed behavior and freeze a versioned delivery artifact.
6. Transfer to the authorized console when its app receiver is available. State
   clearly which visual/gameplay behavior still requires console validation.
