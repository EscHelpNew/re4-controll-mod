# RE9 profile

Select **Controls → Profiles and reset → Controls profile → RE9** in the installer
or overlay. Use RE4's default native controller layout. The profile is a practical
approximation of RE9 controls using actions already present in this Switch port.
Default and your latest Custom remain available in the same picker; changing a
control from RE9 creates Custom automatically. Graphics has its own profiles.

The preset enables free360 look, movement while aiming/using the knife, smooth
right-stick aim, firearm-only gyro at0.80 and a small crosshair. It uses third
person with camera distance1.35. **Controls → Camera → Third-person distance**
adjusts this from1.00 (original framing) to2.00. Increasing it gives Leon less
screen space. This is a camera-position change before the native wall collision,
not a model-size or FOV change. Tight spaces can still pull the camera forward.
First person, optical sights and cinematic cameras retain their own behavior.

| Physical input | Action in this profile |
|---|---|
| Left stick | Native movement; camera-relative movement during supported aim/knife states |
| Right stick | Free look / aim |
| Hold L3 | Run |
| ZL / ZR | Ready gun / fire |
| L + ZR | Ready knife + slash |
| B | Interact / confirm |
| A | Cancel; backward + A quick turn |
| Y with ZL | Reload |
| X | Inventory |
| MINUS / PLUS | Map / pause |
| R | Ashley orders, as in RE4 |

RE4 shares its run, reload, cancel and quick-turn native button. A, Y and L3 are
therefore aliases of that button: Y outside aiming can act as run/cancel, and L3
while aiming can reload. There is no context-sensitive command replacement here.
Native menu/QTE button prompts retain their original labels after remapping.
Keep that in mind when a prompt asks for the game's original button.

This preset does not add RE9 crouching, parrying, quick healing, quick weapon
slots, toggle sprint, modern animations or full camera-relative walking outside
combat. Sensitivity values are this mod's settings, not undocumented RE9 curves.
The distance value is an initial framing choice requiring hardware comparison.

The controller diagrams were visually checked against the
[RE9 in-game PS5 layout screenshot](https://www.spottis.com/img/public/resident-evil-requiem-controls-playstation.jpg),
[RE9 Switch diagram](https://img.gamewith.jp/img/ec96ddc7bf46f4b390c10f9f731e09a2.png)
and [Capcom's original RE4 Switch controls](https://game.capcom.com/manual/bio4/img/manual/en/switch/5.jpg).
The archived screenshots stay in ignored local research; they are not bundled
as app assets. The RE9 web-manual URLs found during research returned404, so the
profile does not claim unverified official sensitivity formulas.
