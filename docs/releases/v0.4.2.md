Fixes saved gyro aiming after a full RE4 restart. The module now has explicit
SD access, retries initial settings reads with a bounded delay, and restores the
saved enable state and sensitivities. Opening the overlay also sends saved settings
automatically; a manual Off/On toggle is no longer needed. Saved Off remains Off.

**Close RE4, open the updated installer and select Install / update mod.** This
updates both the game module and its process permissions; restart RE4 afterward.
The in-game overlay and module must be updated together.

Startup source/error diagnostics, backup recovery, delayed mount, retry exhaustion,
live-setting precedence and activation without toggling have automated tests.
Cold-start acceptance on the console is pending the user's update.
The repository remains private; anonymous in-app downloads require public access.
No personal keys or tokens are included.
