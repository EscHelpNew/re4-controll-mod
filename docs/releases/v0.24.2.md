# RE4 Controls0.24.2 — local console-feedback build

Устранён блокирующий этап109 для штатной структуры костного эффекта Леона.
Игра сохраняет собственный эффект и настоящий скелет; разрешена только
проверенная штатная таблица. Неизвестные или изменённые структуры по-прежнему
отклоняются. Остальные проверки внешности и загрузки ресурсов сохранены.

При прицеливании гранатой в режиме RE6 камера больше не поворачивается за
расчётным пятном. Вместо этого обзор плавно расширяется к70градусам и
возвращается после отпускания. Переход занимает примерно200мс. Направление
броска сохраняется; родная проверка стен получает уже расширенный объектив
и выбирает безопасное положение. При частичном выходе за край экрана пятно
обрезается по границе кадра, а не исчезает целиком. Закрытые геометрией или
устаревшие расчёты по-прежнему скрыты.

Названия оружия и туман теперь рисуются после штатного HUD. Тайминги остаются
500мс появления,2секунды показа и500мс исчезновения. Изменение проверено
сквозным тестом смены настоящих ID оружия; видимость на консоли нужно проверить.

В чемодане под названием оружия показано компактное число силы, например
**1.2**, тем же живым игровым шрифтом, цветом и обводкой. Размер составляет60%
от штатной ячейки шрифта названия. Большая строка пользовательским шрифтом
`Урон:` удалена. Значение и улучшения конкретного экземпляра считаются как раньше.

Включены исправление TMP и все функции0.24.0. Wire18/sharedABI22 сохранены.
После обновления приложения полностью закройте RE4, выполните
**RE4 → Установить/обновить мод** и запустите игру заново.

## Engineering notes

The old109 check treated any active actor3A0 owner as incompatible. Normal player
constructors install AF4798 (count6, tableAF4768), consumed after mesh traversal
through the real actor's bones; the narrowed admission preserves that native path.
Unknown owners remain rejected; relocated pointer literals are not profile guards.

The lens filter is independent of prediction refresh and visibility. Native
grenade camera profile2 and current projection order are exercised, including
the full8-field world-follow output. Native18990 uses FOV for its collision
footprint, so no manual eye relocation is introduced, but the native solver can
choose a different safe eye. Full-up entry may need about200ms for the lens to open;
no guarantee is made for arbitrary points behind the camera.

The new text adapter clones live native glyph styling and uses the native
projection-owning wrapper. It does not infer Cyrillic glyph codes or modify
message channels. Weapon-popup overdraw is a demonstrated ordering risk, not a
proven unconditional native screen clear or sole console cause.
