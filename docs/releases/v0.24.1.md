# RE4 Controls 0.24.1 — local diagnostic build

Исправлено восстановление правого стика и гироскопа при непрерывной стрельбе
из TMP. Штатное состояние готовности может полностью пройти внутри одного
обновления игры; теперь проверенная обычная фаза выстрела TMP также восстанавливает
управление. Защиты для поднятия/опускания оружия, перезарядки, урона и меню
сохранены; устаревшие данные гироскопа при восстановлении отбрасываются.

При прицеливании гранатой в режиме RE6 камера слегка меняет направление, если
реальное расчётное пятно взрыва иначе выйдет из кадра. Положение камеры после
проверки стен, направление броска и физика гранаты сохраняются. Центр пятна
насыщеннее красный; мягкие прозрачные края сохранены. Пятно по-прежнему скрывается,
если точка закрыта геометрией или данные расчёта устарели.

Причина постоянного ожидания внешности на консоли ещё не установлена. Вместо
общего «Ожидание» оверлей показывает конкретный этап и числовой код, а при
несовпадении типа/числа костей — также прочитанное значение. Эти данные нужны
для следующей проверки в игре; ограничения совместимости и безопасности
загрузки моделей не ослаблены. **Это диагностика зависания, не заявление об
исправленной смене внешности.**

Все функции0.24.0 включены: названия оружия с туманом500/2000/500мс, текущий урон
выбранного оружия в чемодане, исправления затемнения и звука при подборе.
Wire18/sharedABI22 не изменены. Полностью закройте RE4, обновите приложение,
выберите **RE4 → Установить/обновить мод** и запустите игру заново.

## Console probe

In normal gameplay open **Game → Character appearance**, select one non-Leon
appearance and read the detailed status after several frames. Report the code
and optional observed value, e.g. `105 / 26`, plus Leon's current costume.
No private pointers, game files or credentials are included in this diagnostic.

Native camera projection is rebuilt before the final look-at call; frustum
regeneration follows it. The framing helper constrains only render direction
using a sphere around the real floor disc and current projection. Native aim,
trajectory, collision queries and wall-safe camera eye remain unchanged. The
conservative cone can engage before a rectangular viewport edge and cannot
smooth a discontinuous physical prediction while also guaranteeing visibility.
