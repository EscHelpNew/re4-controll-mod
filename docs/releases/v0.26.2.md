# RE4 Controls0.26.2 — transport failure observations

Диагностическая сборка для поиска обрыва соединения с игровым оверлеем.
На консоли0.26.1 отображает28773, принимает TCP-соединение и сбрасывает его
до авторизации, в том числе без отправки данных. Причина пока не установлена.
Этот выпуск добавляет наблюдения; восстановления соединения ещё не подтверждено.

Первая ошибка соединения сохраняет этап, файловый дескриптор, результат вызова,
errno, код BSD и прошедшее время. Когда сокет позволяет, сервер отправляет
ограниченную строку `ERR TRANSPORT` с числовыми полями. Данные игры доступны
только после авторизации. Клиент ПК строго проверяет эти поля и сохраняет их
в журнале наблюдения, не отражая произвольный текст ответа.

Резервный журнал `switch/re4-controls/live-debug.log` ограничен32KiB и входит
в автоматический отчёт приложения. При первом обрыве он также сохраняет один
снимок состояния игрового модуля тем же изолированным читающим потоком. В нём нет
ключа подключения, адресов памяти или содержимого запросов. Это позволяет
получить ошибку и состояние игры через отчёт приложения даже при неудачной
отправке ответа по TCP.

Общая сборка также включает параллельную работу над дополнительным улучшением
оружия и счётчиком патронов в чемодане. Обе опции по умолчанию выключены;
настройки переходят на wire19. Поэтому модуль и оверлей устанавливаются вместе.
Диагностические изменения сохраняют принятую камеру гранаты и проверки
совместимости0.26.1. Игровая проверка параллельных опций ещё требуется.
Исправлено сохранение дополнительных улучшений при сбоях чтения или записи SD:
непрочитанное состояние не записывается поверх существующего, а неудачная запись
повторяется. Неизвестное владение восстанавливается по исходному слоту сохранения
перед покупками и записью нового CRC.
Ничего дополнительно устанавливать для Uberhand не требуется: обновляется
существующий RE4 Controls.
