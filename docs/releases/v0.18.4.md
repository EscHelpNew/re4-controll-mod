# RE4 Controls 0.18.4 — local, unpublished

Fixes an update conflict after manually copying our0.16.1 module and later
installing only the overlay. The old overlay-only receipt had zero ownership
for the module. A full update may now migrate only that verified legacy module
with a valid zero-slot receipt; unknown files remain protected. Standard
preflight, backup and receipt publication remain in use. Settings are preserved.

Includes0.18.0 reload movement/steering,0.18.1 playable Ashley shoulder controls,
and0.18.2 fixed shoulder framing. The diagnostic-only0.18.3 adds fixed-path
artifact identities to support reports without disclosing binaries or credentials.

Full host tests, ARM64 module/overlay/NRO build, independent review and public
source/history/package audit passed. Gameplay/camera hardware acceptance is
still pending. Installing a new app does not replace the installed game module:
with RE4 fully closed, choose **RE4 → Install / update mod**, then restart RE4.

Исправляет конфликт обновления после ручного копирования нашего модуля0.16.1
и последующего отдельного обновления оверлея. Установщик распознаёт только
проверенный старый модуль; неизвестные файлы сохраняются. Настройки не сбрасываются.
При полностью закрытой RE4 выберите **RE4 → Установить / обновить мод** и
запустите игру заново. Проверка поведения игры и камеры на Switch ещё требуется.
