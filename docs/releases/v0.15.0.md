# RE4 Controls 0.15.0

## English

- Graphics settings in the installer and in-game overlays for both RE4 and RE6.
- Game screenshot illustrations highlight the textures, edges, distance or shadows
  affected by each supported setting. These are explanatory examples, not previews
  of the selected rendering mode.
- Separate RE6 graphics settings: native defaults, anisotropic filtering and
  anti-aliasing. Native RE6 controls and motion aiming are preserved; unverified
  RE6 shadow and draw-distance controls are not exposed.
- Includes the RE6-based RE4 controls profile, profile selection at the top of the
  controls menu, gyro smoothing, limited vertical stick look and reload movement.
- English/Russian menus, separate settings for each game and reticle preview.

**OTA:** Open RE4 Controls → Updates → check/download the update. Exit with PLUS
and reopen the application after installation. On each game's page, use
**Install / update mod** (RE4) or **Install RE6 module** (RE6) to install the bundled
module and overlays while that game is closed. Updating the NRO alone does not
replace the installed game modules or overlay menus.

The new graphics illustrations have automated renderer coverage; their appearance
on the console and the latest graphics changes still need hardware confirmation.
Use the game's native graphics defaults if a custom mode causes problems.

Assets: `re4-controls.nro`, `re4-controls-sd.zip`, `re4-controls-update.txt`,
`SHA256SUMS`. No personal tokens, keys or game dumps are included. The explanatory
screenshots and their attribution are included under the graphics preview notice.

## Русский

- Настройки графики в установщике и игровых оверлеях для RE4 и RE6.
- Игровые кадры с рамкой показывают, на какие текстуры, края объектов, дальний
  план или тени влияет настройка. Это поясняющие примеры, а не предпросмотр
  результата выбранного режима.
- Отдельные настройки графики RE6: исходные параметры игры, анизотропная
  фильтрация и сглаживание. Штатное управление и гироскоп RE6 сохранены.
  Непроверенные настройки теней и дальности RE6 не добавлены.
- Включены профиль управления RE6 для RE4, выбор профиля первым пунктом,
  сглаживание гироскопа, ограничение вертикального обзора стиком и ходьба
  при перезарядке.
- Русский и английский языки, раздельные настройки игр и предпросмотр прицела.

**Обновление по воздуху:** RE4 Controls → Обновления → проверить/скачать.
После установки выйди кнопкой PLUS и снова открой приложение. При закрытой игре
на её странице выбери **Установить / обновить мод** для RE4 или
**Установить мод RE6** для RE6: это обновит игровые модули и оверлеи.
Само обновление NRO не заменяет уже установленные игровые модули и меню оверлеев.

Новые иллюстрации прошли автоматические проверки отрисовки. Их внешний вид на
консоли и последние изменения графики ещё требуют аппаратного подтверждения.
При проблемах с нестандартным режимом верни исходные настройки графики игры.

Личные токены, ключи и образы игр в релиз не входят. Поясняющие скриншоты
сопровождаются указанием источников в уведомлении graphics preview.
