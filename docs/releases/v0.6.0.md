Adds a Graphics menu to the installer and overlay, with original game settings
as defaults. Filtering supports bilinear, trilinear and AF2x-16x for eligible
mipmapped textures. Handheld SSAA renders900p to720p through the native scaler;
docked output remains native. Both filtering and AA require restarting RE4.

Object distance scales fog-limited loaded-model culling0.50x-2.00x without adding
rooms, changing fog or replacing LOD. Rendered shadows can be Native or Off;
shadow texture resolution is unchanged. Existing control/camera/mapping settings
migrate to v8 and remain intact. Graphics-only reset restores Native options.

Close RE4 and choose Install / update mod, then restart it. Module and overlay
must be updated together (shared ABI12). The new graphics paths have automated
and ARM build checks; on-device visuals/FPS and transitions remain pending.
No personal keys, tokens or game files are included.
