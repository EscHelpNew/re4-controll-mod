# RE4 Controls 0.16.1

## English

- Restore the full native downward knife/firearm aiming range; the overview
  keeps its separate 35-degree stick limit.
- Improve moving fire for verified pistol, shotgun, automatic, rifle, launcher
  and mine handlers, including first automatic shots and rifle bolt recovery.
- Sniper scopes stay stationary: right stick and gyro aim smoothly, left stick
  smoothly changes zoom. Native magnification feedback is preserved.
- RE6 keeps stock FXAA3. Remove the artifact-producing Off/FXAA/FXAA3HQ choices
  and manual AA hook. Old saved AA choices migrate to Native while preserving
  filtering and language. Native RE6 gyro remains unchanged.
- The user confirmed this build working on Switch after deployment. RE4 AF16x
  was separately confirmed after a full game restart. Special weapons and all
  scene/controller combinations have not been exhaustively tested.

**Update:** replace the NRO or update in-app, exit and reopen the installer.
With the games closed, choose **RE4 → Install / update mod** and
**RE6 → Install RE6 module** to update the bundled modules and menus.
The NRO update alone does not replace installed game modules.

RE4 texture filtering also requires closing the game through HOME → X → Close
and relaunching. Returning to the title screen does not apply a new AF setting.

## Русский

- Восстановлен полный штатный наклон ножа и оружия вниз. Для обычного обзора
  сохранён отдельный предел стика ±35°.
- Доработана стрельба в движении для проверенных семейств пистолетов,
  дробовиков, автоматов, винтовок, ракетниц и миномёта, включая первый выстрел
  автомата и восстановление затвора винтовки.
- В снайперском прицеле персонаж неподвижен: правый стик и гироскоп плавно
  наводят, левый стик плавно меняет зум. Штатные индикаторы увеличения сохранены.
- В RE6 оставлено штатное FXAA3. Убраны варианты Off/FXAA/FXAA3HQ, вызывавшие
  артефакты, и ручной перехват AA. Старые настройки сглаживания переводятся
  в штатные с сохранением фильтрации и языка. Гироскоп RE6 остаётся штатным.
- Пользователь подтвердил работу сборки на Switch после передачи. Эффект
  AF16x в RE4 также подтверждён после полного перезапуска игры. Полная проверка
  всего особого оружия, сцен и контроллеров не заявляется.

**Обновление:** замени NRO или обновись из приложения, выйди и открой установщик
заново. При закрытых играх выбери **RE4 → Установить / обновить мод** и
**RE6 → Установить модуль RE6**, чтобы обновить игровые модули и меню.
Одного обновления NRO для замены игровых модулей недостаточно.

Фильтрация текстур RE4 применяется после **HOME → X → Закрыть** и нового запуска.
Возврат в главное меню игры не применяет новую настройку AF.
