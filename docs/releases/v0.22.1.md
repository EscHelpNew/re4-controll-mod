# RE4 Controls 0.22.1 — local camera fix

При смене оружия через D-pad камера сохраняет выбранный вертикальный угол и
состояние свободного обзора. Раньше сброс владельца прицела обнулял угол на
следующем обновлении персонажа, вызывая рывок к базовому положению.

Смена оружия по-прежнему очищает состояние старой анимации, прицеливания,
гироскопа и проекции прицела. Штатные переходы прицелов и FOV сохраняются.
Все функции 0.22.0 включены; wire17 и sharedABI21 не меняются.

Это отдельная локальная сборка исправления. Незавершённая смена внешности из
ветки разработки 0.23.0 сюда не входит. После передачи приложения выберите
**RE4 → Установить/обновить мод**, затем запустите игру заново.
