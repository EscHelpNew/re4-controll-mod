Adds full game-button remapping and a continuous right-stick free camera.

- **Button mapping:** 20 physical game-visible buttons, covering menus and QTE.
  Choose a target or Unbound; swaps and duplicate targets are supported. Physical
  overlay controls remain available to restore mappings. HOME/Capture are system buttons.
- **Camera return speed:** 1.00 is native; lower values slow the return and 0.00
  holds the normal bounded look angle.
- **Free camera 360:** continuous horizontal rotation without return, with native
  vertical limits. Uses Camera sensitivity, deadzone and response curve; requires
  Smooth sticks. Aiming and scripted camera paths retain their own behavior.
- Default sensitivity/speed values are 1.00, except **Gyro aiming speed = 0.80**.
  Existing saved values migrate; reset settings to apply the new defaults.

**Close RE4, update the NRO and choose Install / update mod**, then restart RE4.
Module and overlay must be updated together because the settings/shared format changed.
Core mapping, settings migration, camera timing/gates and both menu implementations
have automated coverage. Hardware acceptance of the new camera/mapping is pending;
the mod remains experimental. No game data, personal keys or tokens are included.

Русский: добавлены «Назначение кнопок», «Скорость возврата камеры» и

по умолчанию 0.80; для существующих настроек нужен сброс или ручное изменение.
