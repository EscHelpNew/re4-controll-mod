# RE4 Controls 0.21.0 — local build

- **Пятно места падения гранаты / Grenade landing spot:** мягкое полупрозрачное
  красное пятно показывает расчётное первое касание пола для трёх обычных гранат.
  Предпросмотр учитывает стены и потолок перед полом; мягкие края растворяются до
  нулевой прозрачности. В обоих меню есть небольшой пример, меняющийся с опцией.
- **Без подтверждения подбора / Skip pickup confirmation:** свежий диалог
  подбора пропускается, а штатная игра добавляет предмет, деньги или сокровище.
  При заполненном инвентаре сохраняется штатное освобождение места.
- **Пропуск стартовых заставок / Skip startup logos:** нажатие кнопки пропускает
  Capcom/CRIWARE через штатное завершение стартовой анимации. Сюжетные ролики
  продолжают использовать свои обычные правила.
- **Убрать покачивание прицела / Remove aiming sway:** отключается штатное
  случайное покачивание при наведении; управление стиками и гироскопом сохраняется.
- Полоска и цифры здоровья появляются за **200 мс**, исчезают за **300 мс**.

Четыре новые опции находятся в разделе **«Игра»**, по умолчанию выключены и
не зависят от профилей управления/графики. Обновление сохраняет прежние настройки.

После обновления приложения полностью закройте RE4, выберите **RE4 → Установить/
обновить мод**, затем запустите игру заново. Новые опции требуют согласованных
модуля и оверлея: settings wire16/shared ABI20. Приложение само по себе не обновляет
уже установленные игровые файлы.

Landing prediction is approximate: it uses the current aiming pose and the
center of the native lateral throw randomness. Future release animation,
movement and changing scene geometry can shift the real landing. No RNG,
projectile or game physics is modified for prediction. An unavailable or unsafe
world query, missing floor, blocked view or invalid camera hides the marker.
Prediction work and geometry are bounded; unusually large collision meshes are
excluded. Menu images illustrate appearance rather than captured gameplay.

Host callback/model/UI tests and native-build verification do not establish
console behavior in every room, inventory state or weapon combination. Physical
gameplay acceptance remains pending. This build is not a new public release.
