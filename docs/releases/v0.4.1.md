RE4 Controls adds proportional sticks and additive firearm-only gyro aiming to
the original Nintendo Switch port of Resident Evil 4.

This first public package includes separate left/right aim settings, four response
curves, gyro speed/deadzone with 10 ms averaging, English/Russian menus, an automatic
HOME shortcut and updates from GitHub Releases.

Download **re4-controls.nro** for the standalone installer, or
**re4-controls-sd.zip** for manual SD installation. Launch the NRO in application
mode, close RE4 and choose **Install / update mod**. An existing Tesla-compatible
overlay loader is required for the in-game menu.

Movement, camera, aiming, gyro and the HOME icon have been verified on the console.
The build remains experimental: special weapons and every scripted/QTE context
have not been exhaustively tested. OTA logic, validation, rollback and the HTTPS
worker have automated coverage; public anonymous OTA requires this repository to
be public. No personal keys or tokens are included or required by users.

Русский: скопируйте NRO на SD, запустите через hbmenu в режиме приложения и выберите
«Установить / обновить мод» при закрытой RE4. Язык меняется в настройках.
Правый стик, гироскоп и значок HOME проверены на консоли. Обновления без токена
станут доступны после открытия репозитория.
