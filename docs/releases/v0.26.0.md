# RE4 Controls0.26.0 — live overlay diagnostics

**Superseded by0.26.1:** console testing found a startup guard regression that
disabled all game hooks (status2/frames0). Do not install this candidate.

Оверлей RE4 Controls открывает **TCP28773** с существующим ключом подключения.
Можно получать диагностику с ПК без ручного переписывания чисел: фактические
версии модуля/оверлея, состояние управления и датчиков, ошибки внешности, этап и
процент загрузки, счётчики подписи оружия, параметры камеры и отрисовки.

Для работы порта запустите RE4 Controls через Tesla внутри игры, затем скройте
его комбинацией вызова оверлея. Отдельный поток продолжит отвечать во время игры.
При выходе из этого оверлея или переключении на другой порт закрывается. В главном
меню есть строка «Диагностический порт» с номером или состоянием запуска.

Сервер читает фиксированный набор полей поддерживаемой сборки RE4. Запросы записи,
произвольные адреса памяти, файловые пути и команды выполнения не предусмотрены.
Ключ не встраивается в сборку и не попадает в диагностический JSON. При отсутствии
ключа или ошибке сетевой службы обычные настройки оверлея продолжают работать.

Клиент ПК использует локальный `data/token.txt` автоматически:

```powershell
.venv/Scripts/python.exe tools/live_diagnostics.py --host 192.168.1.131 snapshot --output build/diagnostics/snapshot.json
.venv/Scripts/python.exe tools/live_diagnostics.py --host 192.168.1.131 watch --seconds 15 --output build/diagnostics/session.jsonl
```

Выходные файлы создаются без перезаписи существующих. JSON ограничен16KiB,
подключение —8секундами; клиент может собирать последовательность снимков.

Для подписи оружия добавлено отдельное наблюдение после нативной команды вывода
текста. Оно сохраняет viewport/scissor и номер события в SharedABI23. Это состояние
CPU при построении GPU-команд, а не чтение готовых пикселей. В JSON сохранены
нулевые и отрицательные конечные значения; `usable` отдельно показывает пригодность
областей для рисования. Кэшированные несинхронные параметры отмечены отдельно.
Причина невидимой подписи и тумана пока не установлена.

Также включены исправления внешности: шесть моделей получают свои отдельные кисти,
у Рамона они уже входят в тело. Тело в игре и чемодане использует собственную цепочку
деталей, устраняя зависимость от рук Леона и неполной классификации правой кисти
светошумовой гранаты. Пальцы используют обычную донорскую позу; хваты и стыки манжет
ещё требуют визуальной проверки. Игровые кости и точки оружия сохраняются.

Собственный нож Краузера заменяет отрисовку только точно проверенного нативного
объекта ножа, сохраняя его условия показа и эффекты. В тело и модель чемодана лезвие
не добавляется.

Для поддерживаемой русской таблицы слово «Атака» и число теперь используют один
игровой шрифт, цвет и размер21px. Буквы определяются по проверяемым соответствиям
четырёх локализованных имён; неизвестный перевод сохраняет резервную подпись.
Камера гранаты, принятая пользователем в0.25.0, не меняется.

После передачи приложения полностью закройте RE4, выполните **RE4 → Установить/
обновить мод** и запустите игру заново. Модуль и оверлей должны быть одной версии:
новый SharedABI23 имеет488байт, настройки wire18 сохранены.
