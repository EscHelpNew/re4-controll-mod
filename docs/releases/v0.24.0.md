# RE4 Controls 0.24.0 — local development build

После успешной смены оружия или гранаты через D-pad рядом со здоровьем героя
появляется название. Подпись связана с настройкой **Игра → D-pad смена оружия**.
Серый наклонный шрифт без обводки и светлая туманная подложка появляются за
500 мс, остаются на 2 секунды и исчезают за 500 мс. При новой смене оружия
предыдущая анимация сразу заменяется. Туман мягко собирается и рассеивается;
его края шире текста слева, справа и снизу.

В чемодане под названием выбранного стрелкового оружия показывается текущая
сила с улучшениями, например **Урон: 1.0**. Значение берётся у конкретного
экземпляра через штатный расчёт игры, округляется до десятых и не зависит от
настройки D-pad. Для пустых ячеек, гранат и остальных предметов строка скрыта.

При включённом пропуске подтверждения подбора отключено связанное с этим окном
затемнение всего кадра. После успешного получения оружия восстанавливается
короткий штатный звук. Проверки места, добавление предмета и размещение в
переполненном чемодане остаются за игрой.

Все функции 0.23.0 сохранены. Форматы wire18/sharedABI22 не изменены. После
обновления приложения полностью закройте RE4, выберите
**RE4 → Установить/обновить мод** и запустите игру заново.

## Engineering scope

The popup publishes only after the native D-pad equip sequence completes and
the exact selected slot/actor still match. Atomic snapshots replace older text;
scene/setting invalidation prevents replay. Text and mist each use one native
independent-triangle batch with bounded vertex counts. Whole-line validation
precedes render commands. Typeface coverage comes from unmodified OFL Liberation
Serif Bold Italic; license and source provenance are included.

Attache capture follows the native hover/drag resolver, selected14-byte record,
one-based upgrade level and native firepower getter, including exclusive levels.
The readout follows active native name text and suppresses stale records. Message
coordinates use512×384; the late HUD uses512×448, so vertical placement is converted.

The pickup callback runs after the native fade setter and before its first yield.
It disables only the authenticated fresh channel0 fade. A successful-acquisition
boundary consumes a matching item/model/thread token before playing bank0/id0xF.
Native grant and rejection paths remain responsible for inventory state.

HUD alignment and type size follow the approved screenshot preview; the original
Leon atlas/anchor was not reused. Physical-console layout, animation, performance,
audio and gameplay acceptance remain pending. Host fixtures cannot establish those.
