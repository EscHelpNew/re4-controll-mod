# RE4 Controls0.18.5 — локальная сборка

- Персонаж остаётся слева при движении вправо: устранено второе запаздывание камеры после проверки стен. Штатная коррекция камеры рядом с персонажем сохранена.
- Движение левым стиком с поднятыми осколочной, зажигательной и световой гранатами. Правый стик продолжает задавать направление прицеливания.
- При обычной ходьбе и беге корпус плавно поворачивается в сторону шага до25°. Направление камеры сохраняется; перед прицеливанием и другими действиями штатная поза восстанавливается.
- Исправление конфликта обновления0.18.4 включено; неизвестные файлы других модов сохраняются.

Полностью закройте RE4, откройте RE4 Controls0.18.5 и выберите **RE4 → Установить / обновить мод**, затем запустите игру заново. Настройки сохраняются.

Локальные проверки не заменяют проверку поведения на Switch. Для приёмки: боковая ходьба Леона/Эшли, поворот правым стиком, все три гранаты, остановка/переход к прицеливанию, движение рядом со стенами и по лестницам.
