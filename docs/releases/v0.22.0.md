# RE4 Controls 0.22.0 — local build

- **Пятно взрыва гранаты / Grenade explosion spot:** расчётное место взрыва
  после отскоков и таймера, вместо первого падения. Для воздушного взрыва пятно
  проецируется на настоящий пол под ним. Центр чуть краснее; мягкие прозрачные
  края сохранены. Если граната гаснет без взрыва, пятно не показывается.
- **D-pad смена оружия / D-pad weapon switching:** вправо/влево — следующее и
  предыдущее доступное оружие из чемодана, включая отдельные экземпляры с разными
  улучшениями. Вверх/вниз — следующий и предыдущий доступный тип гранаты.
  Одинаковые стопки гранат не дублируются в цикле. Пункт находится в «Игра»,
  по умолчанию выключен. Переключение выполняется в безопасном обычном состоянии;
  короткая очередь ожидает завершения действия, меню и QTE сохраняют навигацию.
- Цифры здоровья чуть заметнее: непрозрачность увеличена примерно с40% до50%.
  Полоска остаётся40%; появление200мс и исчезновение300мс сохранены.

Все функции0.21.0 включены. После обновления приложения полностью закройте RE4,
выберите **RE4 → Установить/обновить мод** и запустите игру заново. Формат
настроек wire17 и shared ABI21 требуют согласованных модуля и оверлея; прежние
настройки сохраняются, новая опция D-pad мигрирует выключенной.

Prediction uses the current pose, current geometry/time factor and the center
of native throw randomness. It does not modify RNG or actual projectiles.
Material and water removal are distinguished from a damaging burst. Three native
dynamic-carry rooms (21B/30F/334), unsupported mesh sizes, unresolved trajectories,
missing ground and invalid scenes hide the marker. Future animation, movement
and dynamic geometry can change the real result; this is an approximate position.

D-pad equipment selection uses the game's exact slot and native teardown/load/
initialize sequence. Resource loading can yield; requests run after native player
update with context and ownership checks. Physical-console gameplay validation
remains necessary. This build is not a new public release. Cosmetic character
retargeting is under separate investigation and is not included here.
