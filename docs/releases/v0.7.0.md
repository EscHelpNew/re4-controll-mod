# RE4 Controls0.7.0 — local build, unreleased

Independent control/graphics profiles, optional first-person view, a projected
dot/crosshair, and movement while aiming or using the knife. All new gameplay
modes default to Off. Existing settings and separate domain snapshots migrate.

Install/update the mod while RE4 is closed, then restart the game. The module,
overlay and installer must be updated together (settingsv9, shared ABI13).
The overlay's root offers Controls and Graphics separately.

Movement targets verified Leon/generic firearm and knife states with the native
walking budget, leg motions and existing collision pass. Unsupported handlers
and characters remain excluded. First person retains original assets and native
scope/scripted camera ownership. Console appearance, walls/stairs and attack
acceptance are pending; automated engine callback tests substitute native calls.

No GitHub release or tag is authorized for this version. Prepared local assets
do not publish anything. Personal credentials and extracted game assets are
excluded from the public package.
