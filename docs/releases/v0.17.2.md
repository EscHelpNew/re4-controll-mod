# RE4 Controls 0.17.2 — 2026-11-04

## English

This release includes all changes since published 0.16.1. Local 0.17.0 and
0.17.1 were not published.

- Correct horizontal motion in the app gyro preview to match game aiming.
  Game gyro behavior and saved inversions/sensitivities are preserved; no
  settings migration or reset is needed. The game overlay direction was already correct.
- New RE application artwork and matching HOME shortcut icon.
- The internal RE4 page again shows the original 4; the RE6 page keeps its 6.
- Revised exit handling for B from the main menu and + when launched from the own HOME
  shortcut, addressing the reported black screen on exit. A failed exit request
  keeps the app visible with an error code and retry option. The user confirmed
  basic HOME exit in local 0.17.1; other launchers retain normal hbmenu return.
- Independent RE4 graphics presets in the installer and overlay: **Default**
  restores native graphics; **Custom** recalls the last manual choices;
  **Quality** selects AF16x, Handheld SSAA, object distance 1.75x and native
  shadows. SSAA renders 900p to 720p in handheld mode; docked rendering stays native.
  Selecting Default or Quality preserves your Custom configuration.
- Controller diagnostics shows configured left/right stick deadzones numerically
  and as muted red hatching on all four axes.
- Open **Gyro test** with one **ZL** press in diagnostics or through
  **Control settings → Gyro → Debug mode**. A live red dot previews motion over
  a fixed Leon illustration, using the game's gyro filter and integration.
- Edit seven gyro settings in a live draft. **X** calibrates a stationary
  controller; **Y** recentres the dot and clears preview motion without changing
  settings. **Save and apply**, the eighth row, validates and saves before
  returning to the entry page and selection. **B** cancels; save failure keeps
  the test open and active settings unchanged. Outside the test, diagnostics
  retains **Y** for calibration and **X** for preview reset.

**Install / update:** use `re4-controls.nro` or the in-app updater. After updating,
exit and reopen the app. With the games closed, choose **RE4 → Install / update
mod** and, if used, **RE6 → Install RE6 module** to update modules and overlays.
For manual replacement, including the same version, close the app and games and
replace **all three** `re4-controls.nro`, `bridge.nro` and `game.nro` from this
release in `sdmc:/switch/re4-controls/`. The latter two are in the SD ZIP.
Then reopen the app and install the modules again. Saved settings are preserved.
See [installation instructions](https://github.com/EscHelpNew/re4-controll-mod/blob/main/docs/installation.md).

**Graphics:** fully close RE4 through **HOME → X → Close**, then relaunch it.
Returning to the game menu or reopening the overlay does not fully apply changes.

**Validation / limits:** final host tests and the ARM64 build for 0.17.2
passed. Physical validation of the corrected preview direction and broader
hardware acceptance are pending. Basic HOME exit confirmed in 0.17.1 does not
validate gyro, graphics, every exit path or this new binary. Earlier 0.16.1/AF16x
confirmation does not validate new presets or Quality image quality/performance.
The gyro scene is an illustration, not a recreation of game geometry or FOV.
Special weapons and all scene/controller combinations remain incompletely tested.

**Assets:** `re4-controls.nro`, `re4-controls-sd.zip`, `re4-controls-update.txt`,
`SHA256SUMS`.

## Русский

Релиз включает все изменения после опубликованной 0.16.1. Локальные 0.17.0
и 0.17.1 не публиковались.

- Исправлено горизонтальное движение в предпросмотре гироскопа приложения:
  теперь направление соответствует прицелу игры. Игровой гироскоп и сохранённые
  инверсии/чувствительности сохранены; миграция или сброс настроек не нужны.
  В игровом оверлее направление уже было правильным.
- Новый значок приложения RE и соответствующий значок ярлыка HOME.
- Внутри страницы RE4 снова показана исходная «4»; на странице RE6 сохранена «6».
- Изменён выход по B из главного меню и по + при запуске из собственного ярлыка
  HOME для устранения сообщённого чёрного экрана при выходе. При ошибке запроса
  приложение остаётся видимым с кодом и возможностью повторить выход.
  Пользователь подтвердил базовый выход в HOME в локальной 0.17.1; для других
  загрузчиков сохранён обычный возврат в hbmenu.
- Независимые пресеты графики RE4 в установщике и оверлее: **По умолчанию**
  возвращает штатную графику, **Пользовательский** восстанавливает последний
  ручной выбор, **Качество** включает AF16x, Handheld SSAA, дальность объектов
  1.75x и штатные тени. SSAA — рендер 900p с выводом 720p в портативном режиме;
  в доке рендеринг штатный. Выбор штатного режима или «Качество» сохраняет Custom.
- В диагностике настроенные мёртвые зоны левого/правого стика показаны числами
  и приглушённой красной штриховкой на всех четырёх осях.
- **Проверка гироскопа** открывается одним нажатием **ZL** в диагностике или через
  **Настройки управления → Гироскоп → Режим отладки**. Живая красная точка на
  неподвижной иллюстрации с Леоном использует игровой фильтр и интеграцию движения.
- Семь настроек гироскопа меняются в черновике с живым предпросмотром.
  **X** калибрует неподвижный контроллер, **Y** возвращает точку в исходную
  позицию и очищает движение предпросмотра без изменения настроек.
  Восьмая строка, **Сохранить и применить**, проверяет и записывает настройки,
  затем возвращает на исходный экран с прежним выделением. **B** отменяет
  черновик. При ошибке записи экран остаётся открыт, активные настройки
  сохраняются. В обычной диагностике **Y** по-прежнему калибрует, **X** сбрасывает
  предпросмотр.

**Установка / обновление:** используйте `re4-controls.nro` или обновление из
приложения. После обновления выйдите и снова откройте приложение. При закрытых
играх выберите **RE4 → Установить / обновить мод** и, если используете RE6,
**RE6 → Установить модуль RE6**, чтобы обновить модули и оверлеи. При ручной
замене, включая ту же версию, закройте приложение и игры и замените **все три**
файла `re4-controls.nro`, `bridge.nro`, `game.nro` из этого релиза в
`sdmc:/switch/re4-controls/`. Последние два файла находятся в SD ZIP.
Затем откройте приложение и снова установите модули. Настройки сохраняются.
Подробности — в [инструкции установки](https://github.com/EscHelpNew/re4-controll-mod/blob/main/docs/installation.md).

**Графика:** полностью закройте RE4 через **HOME → X → Закрыть** и запустите
игру заново. Возврата в игровое меню или повторного открытия оверлея недостаточно.

**Проверки и ограничения:** итоговые локальные тесты и сборка ARM64 для 0.17.2
пройдены. Физическая проверка исправленного направления предпросмотра
и общая аппаратная приёмка ожидаются. Базовый выход в HOME, подтверждённый
в 0.17.1, не подтверждает гироскоп, графику, все пути выхода или новый бинарник.
Прежнее подтверждение 0.16.1/AF16x не подтверждает новые пресеты, картинку
или производительность «Качество».
Сцена гироскопа условная и не воспроизводит геометрию
или FOV игры. Особое оружие и все сочетания сцен/контроллеров проверены не полностью.

**Файлы релиза:** `re4-controls.nro`, `re4-controls-sd.zip`,
`re4-controls-update.txt`, `SHA256SUMS`.
