## Automated and native verification

145/145 host cases passed on the candidate and in the complete pre-publication
repeat (`build/tests/run-ituvi512/results.json`). Switch module/overlay/NRO builds, package validation
and public tree/history/archive audit passed. Coverage was not recalculated.

Actual installed component/follow/Rig fixtures cover both supported native
profiles and players, separate combat entries and same-family blends, lens/aspect
independence, independent target projection/parallax, collision and early/late
native handoffs. Rejected or stale sources cannot seed a subsequent entry.
Independent review findings were reproduced and resolved before the final run.

All 3115 main guard rows per profile (3111 unique sites) and 30 SDK guards match
original native images; 52 hooks are unchanged. Shared 384/112/192-byte IPC and the
5808-byte optional camera observation are unchanged. Existing input, gait,
locomotion and camera-pose callback sources retain their protected baseline hashes.

## Other changes since public 0.28.27

Camera-relative lateral running retains native movement admission and step speed.
Manual report downloads include at most five system crash/fatal records alongside
the five bounded application journals; the combined response is at most 1 MiB.
Application gyro sensors run only on diagnostic/test screens. The actual SDK
lifecycle fixture passed 12/12, including stop/reacquire of the same controller.

Earlier startup/sleep hangs are not claimed universally repaired. A short 0.28.31
wake test passed; the longer charging test was deferred. The user attributed the
hangs to a system update; that cause was not independently established here.

## Updating

Fully close RE5, update and manually reopen RE Controls, install the full RE5
mod, restart the game, then reload RE5 Controls from the Uberhand/Tesla list.
Module and overlay both require the new 3115-word proof. A cached older overlay
cannot authenticate this module. Game archives, translation and saves are preserved.
